WINDOWS 11 - QUICK START
1. Extract this entire ZIP.
2. Open the BlackboardSync folder and double-click Install.cmd.
3. Click Install. Wait for Python/dependencies/browser setup, then Open App.
4. Enter your institution's Blackboard Ultra URL and click Sign in / Re-login.
5. Select courses, choose separate destination folders and Save Choices.
6. Use Content Options / Choose Content for assignments, folders and size limits.
7. Click Sync Now. Enable Daily Sync if desired.

Existing users: close the app and run Update-Blackboard-Sync-v0.2.3-FIXED.cmd.
It updates installed program files while preserving all saved setup and history.
You can also reinstall through Install.cmd; settings are kept.

Manual Downloads combines size exclusions and failed downloads/listings.
It provides links and detects existing filenames. New manually placed files can
be recognized automatically; pre-existing copies require version confirmation.
New courses have a 50 MB limit by default. Existing saved limits are preserved.
